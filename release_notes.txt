Rooster v3.27.113 — Release notes
==================================

BACKUP: "MAXIMUM CALL STACK SIZE EXCEEDED" OPGELOST
-----------------------------------------------------
- "Nu backup maken" faalde met de melding "Backup mislukt: Maximum call stack
  size exceeded" zodra de database groot genoeg werd (meer radiologen,
  indelingen en historie). De omzetting naar Base64 verwerkte alle bytes in
  één keer, wat tegen een harde limiet van de JavaScript-engine aanliep.
- Dit is nu opgelost: de data wordt in kleine, vaste blokken verwerkt, ongeacht
  hoe groot de database is. Backups (handmatig én automatisch vóór een
  Excel-import) werken hierdoor weer, ook bij een grote database.

Vorige release (v3.27.112): Excel-export toont nu het volledige jaar met
senioriteitsvolgorde en herleidbare kolomkoppen — zie CHANGELOG.md voor het
volledige overzicht.
