Rooster v3.27.90 — Release notes
==================================

EXCEL-KWALITEIT
---------------
- wb.calcProperties = { fullCalcOnLoad: true } toegevoegd.
  Excel sloeg geen gecachte formulewaarden op, waardoor het bij openen
  alles moest herberekenen en daarbij fouten meldde. Dit vertelt Excel
  expliciet dat het bij openen alles opnieuw moet berekenen.

- UPPER() toegevoegd in alle SUMPRODUCT-formules (telLetterFormule en
  bevatLetterCheck). Lowercase celwaarden zoals 'bo' veroorzaakten
  #VALUE!-fouten. Beide functies (hoofdblad + Activiteit-sheet) zijn
  gecorrigeerd.

WATERMERK + SLIMME IMPORT
--------------------------
- Export schrijft nu een named range 'RoosterApp' in het werkboek.
  Dit is een onzichtbaar watermerk waarmee de import het bestand herkent
  als een Rooster-export, ongeacht hoe het sheet heet.

- Import-logica bijgewerkt:
  * Nieuw bestand (met watermerk): zoekt in alle sheets naar de eerste
    met een Dag/Datum-header — sheetnaam maakt niet meer uit.
  * Oud bestand (zonder watermerk): werkt precies zoals voorheen via
    het 'Indeling YYYY'-patroon als fallback.
